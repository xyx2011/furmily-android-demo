Furmily — app blocking permission demo

Screen recording of the Android Focus feature: picking apps to block, the in-app Accessibility prominent disclosure, enabling the service in system Settings, and the block shield shown when a protected app is opened.

  1. Choose apps from the full list of installed launchable apps (Chrome selected).
  2. Swipe to start Focus — the in-app disclosure appears.
  3. Continue opens Android Settings; enable “Furmily app blocking” and confirm.
  4. Start Focus; opening Chrome shows the “Take a breath” block shield.
